# 🌦️ Weather Forecast Web App

A clean, responsive weather forecast web app that shows real-time weather conditions for any city in the world — built using **HTML, CSS, and JavaScript**.

## 📖 Introduction

Checking the weather shouldn't require ten taps and five ads. This project is a lightweight, no-login, no-clutter weather app — just search a city and get instant, accurate weather information along with useful highlights like UV index, humidity, and air quality.

## ❓ Problem It Solves

Most weather apps are heavy, cluttered with ads, or require sign-ups just to check tomorrow's forecast. Users often need a **quick, distraction-free way** to check current conditions and short-term forecasts for any location without installing an app.

## ✅ Solution

This web app solves that by providing:
- A **single search bar** to instantly fetch weather for any city.
- A **clean dashboard-style UI** showing temperature, condition, and key highlights at a glance.
- **Unit switching (°C/°F)** and **hourly/weekly toggle** — all without page reloads.
- **100% browser-based** — no installation, works on any device with internet.

## ✨ Features

- 🔍 **City Search** – Search weather for any location worldwide.
- 🌡️ **Current Weather Display** – Live temperature, date, time, and condition.
- 🎨 **Dynamic Weather Icons** – Icon changes automatically based on real conditions.
- 🔄 **Unit Toggle** – Switch instantly between Celsius and Fahrenheit.
- 📅 **Hourly & Weekly Forecast** – View short-term or extended forecast.
- 📊 **Highlights Panel** – UV index, wind status, sunrise/sunset, humidity, visibility, and air quality.
- 📱 **Fully Responsive** – Works smoothly on mobile, tablet, and desktop.

## 🧭 Navigation / How to Use

1. Open the app in your browser.
2. Type a city name in the search bar and hit search.
3. View current weather instantly on the main card.
4. Toggle between **°C / °F** using the unit switch.
5. Switch between **Hourly** and **Weekly** tabs to see forecast trends.
6. Scroll down to check the **Highlights** section for detailed metrics.

## 📋 Requirements

- A modern web browser (Chrome, Edge, Firefox)
- Internet connection (for live API data)
- A free API key from [OpenWeatherMap](https://openweathermap.org/api)

## 🚀 Installation / Run Locally

```bash
git clone https://github.com/Nanc199/Weather-Forecast-Web-App-.git
cd Weather-Forecast-Web-App-
```

Then simply open `index.html` in your browser — no build step required.

> Add your OpenWeatherMap API key inside `js/script.js` before running.
